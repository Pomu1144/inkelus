    Passwords
    
        
    
      
    
      
    
        
    
          
    Saved logins the agent browser can use on sites that need you to sign in. They're stored only on this computer, encrypted with a master password you choose (AES-256, key made with 600,000 rounds of PBKDF2), and they're encrypted and decrypted here in this page. The app never stores your master password. The AI never sees a password: when it needs to log in, you're asked each time, and the login is only filled on the site it was saved for. There's no way to recover a forgotten master password.

    Web sandbox
    
          
    __APP_NAME__ has its own built-in, read-only browser for the model. It never touches your real browser: no cookies or logins, no JavaScript, no forms, nothing saved to disk. Turn it on per chat with the Web button in the chat header. Needs a model that supports tool calling (e.g. qwen2.5, qwen3, llama3.1+, mistral-nemo).
    
          
          
          
          
        
    
        
    
          
    Agent browser
    
          
    Turn on Browser in a chat's header to let the model use a real browser window: open pages, click, type, choose options and press keys. It starts your installed Chrome (or Edge or Chromium) as a separate window with its own private profile, so it shares nothing with your everyday browser or any other browser product. Each chat gets its own tab. When a site needs a login, it asks you to pick one from Passwords and fills it in without the AI seeing it; or open the window here and log in yourself, and the profile remembers it. Needs a model that supports tool calling.
    
          
          
          
          
    
        
    
        
    
          
    Work context
    
          
    Pull requests from GitHub, issues from Jira and recent email, linked where they mention each other, on the Context page. Turn on Context in a chat to let the model read them. Everything is read-only (nothing is changed in GitHub or Jira, email isn't marked as read) and the synced copy stays on this computer. Tokens and passwords are saved in the app's settings file, like server API keys.
